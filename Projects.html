Nonprofit Live Streaming and Fundraising Platform

Standardized AV, networking, and remote operations · Southeast Michigan

Designed and implemented a reliable, repeatable live streaming platform for nonprofit services and fundraising events, emphasizing signal integrity, synchronization, and operational stability. The system was later standardized, expanded to support multiple cameras, and extended to accommodate long-distance outdoor events without disrupting existing workflows.

  • Video capture: Deployed strategically positioned PTZ cameras as primary and auxiliary capture sources, enabling flexible coverage while maintaining consistent framing.
  • Signal flow: Routed SDI output from the primary camera into Blackmagic Design switchers and Web Presenters, feeding a dedicated streaming and editing workstation for live broadcast and recording to YouTube. HDMI output was simultaneously distributed via a matrix and Ethernet-based HDMI extenders to multiple in-building displays.
  • Audio synchronization: Integrated the house sound system directly into the streaming pipeline to eliminate audio–video sync issues during live broadcasts.
  • Network design: Assigned static IPs to all cameras, powered them via PoE, and isolated the streaming infrastructure within a dedicated VLAN optimized for video traffic.
  • Remote operation: Enabled off-site stream control through a secure VPN tunnel between the editor workstation and the facility.
  • Outdoor expansion: Deployed a point-to-point wireless bridge to extend the network approximately 700 feet to support outdoor events.
  • Edge infrastructure: Installed an outdoor-rated network cabinet with a PoE switch to support recurring outdoor camera deployments while maintaining seamless integration with the existing streaming system.
  • Standardization: Produced diagrams, configuration documentation, and operational checklists to enable repeatable deployment and handoff to other operators.

On-Prem Server Rebuild and Power Resilience Implementation

Infrastructure recovery and continuity planning · SMB environment

Led a full infrastructure remediation for a client experiencing frequent power outages caused by nearby construction, which resulted in downtime, early closures, and prior data loss. The engagement focused on eliminating single points of failure and restoring long-term operational stability.

  • Problem: Power interruptions caused server instability and data loss. Existing hardware lacked redundancy, and no reliable backup strategy was in place.
  • Server design: Scoped and built a new on-premises server using server-grade hardware, including redundant power supplies and multi-disk storage.
  • Storage strategy: Implemented a RAID 5 configuration to balance cost, performance, and fault tolerance, with spare components available for emergency replacement.
  • Identity and services: Installed Windows Server 2022 and deployed Active Directory, using scripts to provision users and groups, configure Group Policy controls, and standardize access.
  • Application support: Coordinated with software vendors to host required databases and applications, maintaining continuity of daily operations.
  • Power resilience: Connected redundant server power supplies to separate PDUs backed by independent UPS units, with network monitoring to detect and respond to power events.
  • Backup and recovery: Deployed a dedicated NAS for daily backups, with routine restore testing to verify data integrity and recovery reliability.
  • Constraints: Designed the solution entirely on-premises due to operational limitations preventing cloud adoption.
